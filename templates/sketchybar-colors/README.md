<h2 align="center">Ricekit for <a href="https://github.com/FelixKratz/SketchyBar" rel="noreferrer noopener" target="_blank">SketchyBar</a></h2>

### Usage

Add to your `sketchybarrc`:

```bash
source "$CONFIG_DIR/colors.sh"
```

Then use variables like:

```bash
--bar color=$BAR_COLOR border_color=$BAR_BORDER_COLOR
```
