# Osaka Jade Desktop assets

`wallpapers/desktop.jpg` is the first Osaka Jade wallpaper distributed by
Omarchy under the MIT License. It is a byte-for-byte copy of the source
recorded in `themes/osaka-jade/ATTRIBUTION.md`.

`screenshots/desktop.jpg` was captured from the clean Tart VM acceptance run
after RiceKit installed and applied this Rice. The frame shows the RiceKit
SketchyBar starter and the active JankyBorders outline around the RiceKit app.
